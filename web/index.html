Importar backup (.json)

Restaura o arquivo gerado por "Exportar dados": lançamentos (com valor zero ou negativo, notas e ids originais) e configurações. Lançamentos com o mesmo id são sobrescritos, então repetir é seguro. Nada é apagado. Pode demorar alguns minutos.
